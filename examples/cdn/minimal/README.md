# Quickstart CDN

Serví esta carpeta con `python3 -m http.server 8001` y abrí http://localhost:8001.
No requiere instalar dependencias ni compilar. Necesita Internet y un navegador
moderno con imports JSON.

`index.html` contiene toda la integración: CSS, import map, contenedor con altura,
import de `plan.json`, constructor y aceptación de `statusrequest` con `setProgress`.
El plan incluye Lógica, Algoritmos y Sintaxis del K23, con sus correlativas completas.
